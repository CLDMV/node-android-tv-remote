# @cldmv/node-android-tv-remote v2.1.4 Changelog

**Release Date**: September 2026
**Release Type**: Patch

---

## Overview

Version 2.1.4 picks up `@devicefarmer/adbkit` 3.3.9 in the lockfile, bumps `@eslint/css` to 2.0.0, removes two unused bindings from the screencap code path, and wires bot identity secrets into the release workflows. It was released on GitHub (tag `v2.1.4`, release PR [#10](https://github.com/CLDMV/node-android-tv-remote/pull/10)) but did not reach npm, whose latest version is still 2.1.0.

The only runtime-file change is dead-code removal in `src/lib/android-tv-remote.mjs`; behavior is unchanged. The declared `@devicefarmer/adbkit` range (`^3.3.8`) did not change, `engines`, `exports`, and `main` are unchanged.

---

## 🐛 Bug Fixes

### Unused code removed from `screencap`

The unused `pipeline` import from `stream/promises` and the unused `writeStreamStartTime` / `writeStreamTime` timing variables around `createWriteStream` were removed from `src/lib/android-tv-remote.mjs`. No behavior changes.

---

## 🔧 CI & tooling

- **Bot identity secrets passed to release workflows** — `feature-pr.yml`, `hotfixes-release.yml`, and `next-release.yml` now map `CLDMV_BOT_NAME` / `CLDMV_BOT_EMAIL`.
- **`hotfix-redirector.yml` can sign cherry-picks** — it now also maps `CLDMV_BOT_GPG_PRIVATE_KEY` / `CLDMV_BOT_GPG_PASSPHRASE` (needed when redirecting Dependabot security PRs onto `hotfixes`) and declares top-level `permissions: contents: read`.
- **Lint cleanups in dev scripts** — unused catch bindings renamed to `_` in `scripts/postinstall.mjs` and several `tools/` scripts; `dev/tools/retry-init-adb.mjs` test now awaits `createRemote`.
