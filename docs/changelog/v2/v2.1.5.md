# @cldmv/node-android-tv-remote v2.1.5 Changelog

**Release Date**: October 2026
**Release Type**: Patch

---

## Overview

Version 2.1.5 is a maintenance release with no runtime code changes. It syncs the v4 workflows with the `CLDMV/.github` v4.29.2 templates and adds the bundle-size workflow, fixes the CI required-check mirror so a skipped run can no longer satisfy the merge ruleset, stamps uniform file headers, and takes a round of development dependency updates. Like the releases since v2.1.1, it was released on GitHub but did not reach npm.

---

## 🔧 CI & tooling

- **v4 workflows synced with `CLDMV/.github` v4.29.2 templates, plus bundle-size measurement** ([#30](https://github.com/CLDMV/node-android-tv-remote/pull/30)) — adds the `bundle-size.yml`, `provenance.yml`, `release-merge.yml`, `member-auto-merge.yml`, `dependabot-recreate.yml` and `pr-notify.yml` callers; bundle size is measured on the published JS files, and the release-merge workflow list is restored to the template's.
- **Skipped PR-run mirror no longer satisfies `✅ Required PR Check`** ([#34](https://github.com/CLDMV/node-android-tv-remote/pull/34)) — GitHub counts a skipped required check as passing, which could let a PR merge before its tests finished. The skipped job no longer posts under the required name.
- **Uniform file headers** ([#33](https://github.com/CLDMV/node-android-tv-remote/pull/33)) — adopts the shared CLDMV `fix-headers` config (`.configs/fix-headers.json`, new `fix:headers` script) and stamps headers across the source, scripts, tests, tools and workflows. Only comment headers changed.
