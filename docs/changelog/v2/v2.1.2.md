# @cldmv/node-android-tv-remote v2.1.2 Changelog

**Release Date**: August 2026
**Release Type**: Patch

---

## Overview

Version 2.1.2 is a CI-only patch that changes how the repository's CI workflow derives its release base and handles concurrency. It was released on GitHub (release PR [#8](https://github.com/CLDMV/node-android-tv-remote/pull/8); no git tag was created for this version) but did not reach npm, whose latest version is still 2.1.0.

No runtime code changed. The only edits are to `.github/workflows/ci.yml` and the version bump in `package.json` / `package-lock.json`.

---

## 🔧 CI & tooling

- **Release-relevant CI runs are never superseded** — `ci.yml` now keys its concurrency group per ref and appends the run id for pushes to the release base branch, `next`, `hotfixes`, and for the `next` / `hotfixes` release PRs, so each of those runs completes and posts its own check instead of being cancelled. Feature branches and feature PRs still cancel superseded runs.
- **Release base derived, not hardcoded** — the base branch is taken from the `CLDMV_RELEASE_BASE` repository variable, falling back to the repository's default branch, rather than assuming `master` or `main`.
