# @cldmv/node-android-tv-remote v2.1.1 Changelog

**Release Date**: August 2026
**Release Type**: Patch

---

## Overview

Version 2.1.1 moves the project onto the CLDMV v4 release flow and replaces its Jest setup with vitest. It was released on GitHub (tag `v2.1.1`, release PR [#6](https://github.com/CLDMV/node-android-tv-remote/pull/6)) but did not reach npm, whose latest version is still 2.1.0.

The one runtime-visible code change is a small `@devicefarmer/adbkit` import-interop fix in `src/lib/android-tv-remote.mjs`. Consumers should note two dependency-level changes that ship with this version: the `sharp` dependency range moved from `^0.34.4` to `^0.35.3`, and `engines.node` was raised (see Breaking Changes). The public API, `exports`, and `main` entry points are unchanged.

---

## 💥 Breaking Changes

### Node.js 18 is no longer supported (despite being a patch)

`engines.node` moved from `^18.17.0 || ^20.3.0 || >=21.0.0` to `>=20.9.0`, because the `sharp` 0.35 runtime dependency requires Node.js >=20.9.0 at install. Projects on Node.js 18 or early Node.js 20 releases must move to Node.js 20.9.0 or newer (or stay on v2.1.0).

---

## 🐛 Bug Fixes

### `adbkit` import resolves under both Node and Vite/Rollup CJS interop

`@devicefarmer/adbkit` is a plain CommonJS package. Under plain Node ESM/CJS interop the default import is `module.exports` (so `.Adb` holds the class), while under Vite/Rollup-based interop, for example vitest with the module inlined, the default import unwraps straight to the class. `src/lib/android-tv-remote.mjs` previously assumed the first shape (`adbkit.Adb`); it now uses `adbkit.Adb ?? adbkit` and handles both. Behavior under plain Node is unchanged.

### Unused `createRemote` import removed from the `adb-response` dev tool

The release PR title references removing an unused `createRemote` import in `adb-response.mjs`. That script lives under the repository's dev tooling and is not part of the published package.

## 🔧 CI & tooling

- **v4 release-flow workflows adopted** — the full `.github/workflows/` set (CI, release PR openers for `next` and `hotfixes`, publish, CodeQL, Scorecard, dependency review, Dependabot auto-merge, CLA, labeler, stale, tag health, and others) plus `.github/dependabot.yml` were added.
- **Test suite moved from Jest to vitest** — `jest` was removed; tests now run through `@cldmv/vitest-runner` (`tests/run-vitest.mjs`, `.configs/vitest.config.mjs`). The old `test/*.test.mjs` Jest files were replaced by `tests/api-surface.test.vitest.mjs`.
- **npm scripts added** — `test`, `test:watch`, `coverage`, `ci:coverage`, `lint`, `lint:fix`, `format`, `format:check`, and no-op `build` / `build:ci` scripts.
- **Manual scripts reorganized** — the ad hoc scripts formerly in `test/` moved to `tools/` (device and screencap utilities, plus a new `tools/android-tv-remote-live-check.mjs`) and `dev/tools/` (debug helpers).
- **ESLint configuration updated** (`eslint.config.mjs`).
