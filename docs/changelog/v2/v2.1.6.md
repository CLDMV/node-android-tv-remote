# @cldmv/node-android-tv-remote v2.1.6 Changelog

**Release Date**: October 2026
**Release Type**: Patch

---

## Overview

Version 2.1.6 is a CI and lockfile release with no runtime code changes. It corrects v2.1.5's required-check fix so in-repo PRs report their status from a job that actually runs, and refreshes the lockfile. It was released on GitHub but did not reach npm.

---

## 🔧 CI & tooling

- **In-repo PR mirror job runs instead of being skipped** ([#37](https://github.com/CLDMV/node-android-tv-remote/pull/37)) — the `✅ Required PR Check` mirror now runs on the `pull_request` event for in-repo PRs and reports the CI result.
