# @cldmv/node-android-tv-remote v2.1.9 Changelog

**Release Date**: October 2026
**Release Type**: Patch

---

## Overview

Version 2.1.9 fixes a medium-severity `brace-expansion` advisory in the development toolchain and updates the test and lint tooling. The net change against v2.1.8 is `package.json` (the version field only) and `package-lock.json`. No source file, script, workflow or documentation changed, the declared dependency ranges are unchanged, and the runtime dependencies (`@devicefarmer/adbkit` and `sharp`) keep the same locked versions.

`@cldmv/vitest-runner` 1.5.3 raises its own `engines.node` to `>=22.12.0` and brings in `chalk` 6, which needs Node.js 22 or later. Running the repository's tests already needed Node.js 22.12 or later because of Vitest 5, and the CI matrix starts at 22.12.0, so this changes nothing in practice. The package's own `engines.node` stays `>=20.9.0`.

## 🔒 Security

### `brace-expansion` 5.0.9 → 5.0.12 ([#55](https://github.com/CLDMV/node-android-tv-remote/pull/55))

Fixes GHSA-q2hr-2g5m-vwhr (CVE-2026-102277), a medium-severity (CVSS 5.3) denial of service: expanding input shaped like `{a},b}` takes time quadratic in the number of literal `}` characters, so a large crafted pattern can block the event loop. `brace-expansion` is a transitive dependency of `minimatch`, which only the development tooling pulls in, and the lockfile records it as development-only, so it is not part of the installed package. The repository's Dependabot alert for it ([alert 41](https://github.com/CLDMV/node-android-tv-remote/security/dependabot/41)) closes once this release reaches `master`.

[#55](https://github.com/CLDMV/node-android-tv-remote/pull/55) was Dependabot's security update, redirected by the hotfix workflow to be re-applied on top of the hotfix branch's own tip. It was merged into `next` rather than `hotfixes`, so the fix ships in this release and not as a separate hotfix release. Nothing else is pending on the hotfix lane: `hotfixes` has no commits beyond `master`.

## 🔧 Dependencies

All changes are to development dependencies, and only the lockfile moved. The `package.json` ranges are unchanged.

- **`@cldmv/vitest-runner` 1.5.1 → 1.5.3** ([#61](https://github.com/CLDMV/node-android-tv-remote/pull/61)). Its `engines.node` rises from `>=20.19.0` to `>=22.12.0` and its `chalk` dependency moves from 5.6.2 to 6.0.1 (`engines.node` `>=22`), as described above. The runner's 1.5.3 release also changes how its CommonJS entry loads the ES module build, which does not affect how this repository runs its tests.
- **Vitest group** ([#56](https://github.com/CLDMV/node-android-tv-remote/pull/56)): `vitest`, `@vitest/coverage-v8`, `@vitest/mocker` and `@vitest/spy` 5.0.2 → 5.0.3, with `vite` 8.3.1 → 8.3.2, `rolldown` and its platform bindings 1.2.11 → 1.2.12, `@oxc-project/types` 0.151.0 → 0.152.0 and `why-is-node-running` 3.2.2 → 3.2.1 (the exact version Vitest 5.0.3 depends on, so this one moves down).
- **ESLint** ([#57](https://github.com/CLDMV/node-android-tv-remote/pull/57)): `eslint` 10.11.0 → 10.12.0.
- **`globals`** ([#59](https://github.com/CLDMV/node-android-tv-remote/pull/59)): 17.12.0 → 17.13.0.
- **Security** ([#55](https://github.com/CLDMV/node-android-tv-remote/pull/55)): `brace-expansion`, described above.
