# @cldmv/node-android-tv-remote v2.1.3 Changelog

**Release Date**: September 2026
**Release Type**: Patch

---

## Overview

Version 2.1.3 bumps the vitest toolchain to 5.x, fixes the peer-dependency resolution error that bump caused, and reformats the library source and README with Prettier. It was released on GitHub (tag `v2.1.3`, release PR [#22](https://github.com/CLDMV/node-android-tv-remote/pull/22)) but did not reach npm, whose latest version is still 2.1.0.

The edits to `src/lib/android-tv-remote.mjs` are formatting only (quote style, line wrapping, whitespace) with no change in behavior. Runtime dependencies, `engines`, `exports`, and `main` are unchanged.

---

## 🔧 CI & tooling

- **vitest 5 toolchain** — `vitest` and `@vitest/coverage-v8` are bumped together to ^5.0.0. The coverage package had to follow the vitest bump to avoid an `ERESOLVE` install failure, which is what the release PR [#22](https://github.com/CLDMV/node-android-tv-remote/pull/22) addresses. This builds on the `@vitest/mocker` 4.1.10 → 5.0.0 Dependabot bump ([#18](https://github.com/CLDMV/node-android-tv-remote/pull/18)), which landed directly on `master` between 2.1.2 and this release.
- **Workflow files refreshed** — the `.github/workflows/` set and `.github/dependabot.yml` were reformatted (indentation) with no functional intent noted.
- **Dev scripts reformatted** — `dev/tools/debug-chars.mjs`, `dev/tools/debug-imports.mjs`, `dev/tools/debug-keyboard-creation.mjs`, and `tools/keyboard-test.mjs`.
