# `@cldmv/node-android-tv-remote` v2.2.1 Changelog

**Release Date**: November 2026
**Release Type**: Patch
**Branch**: `release/2.2.1`

---

## Overview

Version 2.2.1 lowers `engines.node` from `>=22.22.0` to `>=22.12.0`. v2.2.0 set the package floor to the version its development toolchain needs, which was higher than anything the package needs at runtime. The runtime floor is now the one its dependencies declare, and the toolchain floor moves to npm's `devEngines`, where it only applies to working on this repository.

The exported API and the remote's behavior are unchanged from v2.2.0.

---

## 📦 Requirements

### `engines.node` is `>=22.12.0` ([#89](https://github.com/CLDMV/node-android-tv-remote/pull/89))

`engines.node` drops from `>=22.22.0` to `>=22.12.0`, the floor that `@devicefarmer/adbkit` 4 and its `commander` 15 dependency declare. `import` works from 22.12.0. `require()` loads the ESM build through Node's `require(esm)`, which runs without warnings from 22.13.0, so the `ERR_REQUIRE_ESM` message that `require()` throws on a Node.js without `require(esm)` now names `>=22.13.0`.

Developing the package still needs Node.js 22.22.0 or later. That floor is now declared in `devEngines` (`runtime` `node` `>=22.22.0`, `onFail: "error"`), so npm enforces it in a checkout of this repository and never for consumers installing the package.
